GUÍA DE EJECUCIÓN: PROYECTO FINAL NOSQL / MONGODB

1. Requisitos Previos
- Node.js instalado en el sistema.
- Conexión a MongoDB activa.

2. Instalación Inicial
Abrir la terminal en la carpeta raíz del proyecto y ejecutar:
npm install

3. Configuración del Entorno (package.json)
Scripts optimizados con ejecución local (npx) para evitar errores de comandos en Windows:

"scripts": {
  "start": "node src/app.js",
  "dev": "npx nodemon src/app.js",
  "ui": "npx live-server --port=5000",
  "test": "echo \"Error: no test specified\" && exit 1"
}

4. Ejecución del Proyecto (Paso a Paso)

- Terminal 1 (Backend y Base de Datos):
  npm run dev

- Terminal 2 (Frontend / Interfaz Web):
  npm run ui

Nota: El navegador se abrirá automáticamente en http://localhost:5000 mostrando el index.html ubicado en la raíz.
